# ربط المشروع بمستودع GitHub ونشر التحديثات

## الوضع الحالي
المشروع مربوط حالياً بمستودع Lovable الداخلي فقط. لا توجد مزامنة مع
`github.com/midgard2312-stack/vmaria`، لذلك التحديثات التي رفعتها هناك لا تصل
إلى هذا المشروع ولا تدخل في النشر.

## الخطوة التي تنفّذها أنت (لا يمكنني تنفيذها نيابةً عنك)
تفعيل المزامنة يتم من واجهة Lovable وليس من الكود:

1. من قائمة **+** في أسفل يسار مربع المحادثة → **GitHub** → **Connect project**.
2. الموافقة على تطبيق Lovable على GitHub، واختيار حساب `midgard2312-stack`.
3. إتمام الربط بإنشاء/اختيار المستودع.

ملاحظة مهمة: Lovable لا يدعم حالياً *استيراد* مستودع GitHub موجود. الربط ينشئ
مستودعاً من كود المشروع الحالي ثم تصبح المزامنة ثنائية الاتجاه بعدها. أي تعديلات
موجودة في `vmaria` على GitHub قبل الربط لن تُسحب تلقائياً.

## بعد الربط
- أي دفعة (push) إلى الفرع الافتراضي تُزامَن تلقائياً إلى المشروع خلال ثوانٍ.
- تغييرات الواجهة تحتاج ضغط **Publish/Update** لتظهر على الموقع المنشور؛ تغييرات
  الخادم/قاعدة البيانات تُنشر مباشرة.

## البديل إن كانت تحديثاتك على GitHub مهمة الآن
أخبرني بما يحتويه التحديث (أو اجعل المستودع عاماً وأعطني رابط الملفات)، وسأطبّق
تلك التعديلات يدوياً داخل المشروع ثم ننشر — هذا يضمن عدم ضياع عملك عند الربط.

## النشر
بعد اكتمال أحد المسارين أعلاه، أنشر النسخة الحالية على `vmaria.lovable.app`
وأتحقق من أن الصفحة الرئيسية والمشغّل يعملان على النسخة المنشورة.
