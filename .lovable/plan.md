# مزامنة تحديثات GitHub ونشرها

المستودع `midgard2312-stack/vmaria` عام، وقرأت منه التحديثات مباشرة. مقارنة مع
كود المشروع الحالي: هناك 3 دفعات جديدة (اليوم) غير موجودة هنا، والملفات المتأثرة
لا تزال مطابقة لنقطة الأساس محلياً، لذلك يمكن نقل التغييرات يدوياً بدون تعارض.

## ما سأنقله من GitHub

1. **مساعد ماريا العائم** — ملف جديد `src/components/MariaAssistant.tsx`: نافذة
   محادثة صغيرة أسفل الشاشة، سجل محادثة محفوظ، أزرار اقتراحات جاهزة، ومسح
   المحادثة. تُركَّب داخل `src/routes/__root.tsx` لتظهر في كل الصفحات.
   (دوال الخادم `chatWithMaria` / `getChatHistory` / `clearChatHistory` موجودة
   أصلاً في المشروع، فالمساعد يعمل فوراً.)
2. **قسم لقطات الفيلم** في صفحة الفيلم: شبكة بطاقات مرقّمة بعنوان اللقطة، وقت
   البداية، شرح مختصر، ووسوم — الضغط ينقل التشغيل إلى تلك اللحظة.
3. **تحسين نصوص الذكاء الاصطناعي**: أوصاف الأفلام وعناوين اللقطات وشخصية ماريا
   صارت أوضح وبلهجة عراقية خفيفة مع صياغة محترمة للموضوعات الناضجة.
4. **README** للمشروع.

## نقطتان تحتاجان قرارك (سأتبع GitHub افتراضياً)

- تحديث GitHub يضيف قسم اللقطات في صفحة الفيلم، وأنت سابقاً طلبت حذف عرض
  "اللقطات المميزة". النسخة الجديدة مختلفة (فهرس زمني للانتقال) لذلك سأضيفها.
- تحديث GitHub يجعل مشغل الفيلم نفسه مكتوم الصوت (`mute`)، بينما طلبك السابق كان
  صوت طبيعي عند تشغيل الفيلم وكتم في التريلر فقط. **سأُبقي الفيلم بصوت طبيعي**
  وأترك الكتم للتريلر، إلا إذا قلت غير ذلك.

## تفاصيل تقنية

- الملفات: إضافة `src/components/MariaAssistant.tsx` و`README.md`؛ تعديل
  `src/routes/__root.tsx` و`src/routes/videos.$id.tsx` و`src/lib/video.functions.ts`.
- لا تغييرات في قاعدة البيانات؛ جدول `chat_messages` موجود.
- الحفاظ على تحسينات موجودة محلياً (قص إطار مشغل Drive، الرجوع للمكان السابق،
  استئناف المشاهدة) دون التراجع عنها.
- التحقق: بناء نظيف + فتح الرئيسية وصفحة فيلم للتأكد من ظهور المساعد واللقطات.
